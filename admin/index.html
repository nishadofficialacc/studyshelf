Shared workflow

  1. The client uploads the full paid PDF to Payhip and publishes its product there.
  2. Either approved editor signs in here and creates a Draft with the Payhip link and accurate listing details.
  3. After reviewing the product, enable Published on storefront and click Save.
  4. The public website updates automatically from Firestore. Check the product, price and checkout link.
  5. Use Download backup JSON regularly for a separate catalog backup.

Security: Only Firebase-authenticated accounts that have an authorized role can read drafts or write products. The site does not expose Firebase administrator credentials. All product data in the storefront is public once published.

Files: Upload paid PDFs to Payhip only. Public sample PDFs may be placed in GitHub assets/; no file uploads are implemented in this V3 dashboard.
